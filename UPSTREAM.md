# Source and scope

The files in this public code handoff were copied from the canonical private
`FluentFlier/ASDDS` repository at commit
[`a223963cd1da8d89148b502b7b12af6d4eefb553`](https://github.com/FluentFlier/ASDDS/commit/a223963cd1da8d89148b502b7b12af6d4eefb553).
That is the source revision, not a version or release identifier for this
public handoff.

This repository contains selected Python and MATLAB code, developer tests, and
technical documentation. It intentionally excludes raw and cleaned research
data, correspondence, generated figures, manuscript files, and research backup
archives. The full rescue pipeline requires input data from the separate
research archive; no data are bundled here.

The Jetson deployable mirror is retained alongside `code/` so users can inspect
the recommended runtime and its self-contained handoff. Use launcher option 2,
`led_sleep_detect_clean.py`; legacy launcher modes remain historical.
